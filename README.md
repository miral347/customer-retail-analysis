 # Customer Retail Data Analysis and Machine Learning Model Comparison

## Project Overview

This project focuses on analyzing customer retail transaction data and comparing the performance of multiple machine learning classification models. The dataset is preprocessed, visualized, and used to train different algorithms to evaluate their predictive capabilities.

## Objectives

* Perform data preprocessing and cleaning.
* Explore retail customer data through visualization.
* Apply machine learning classification algorithms.
* Compare model performance using accuracy metrics.
* Visualize the comparison results.

## Dataset Features

The project utilizes retail transaction data containing features such as:

* Quantity
* Unit Price
* Country

The target variable is encoded and used for classification.

## Technologies Used

* Python
* Google Colab
* Pandas
* Matplotlib
* Scikit-learn

## Machine Learning Models

### Logistic Regression

A linear classification algorithm used as a baseline model.

### Decision Tree Classifier

A tree-based classification model capable of capturing non-linear relationships.

### K-Nearest Neighbors (KNN)

A distance-based classification algorithm that predicts classes based on nearest neighbors.

## Workflow

1. Import dataset.
2. Handle missing values.
3. Select relevant features.
4. Encode categorical variables.
5. Split data into training and testing sets.
6. Train machine learning models.
7. Evaluate model accuracy.
8. Compare model performance using visualization.

## Results

The project compares the accuracy of:

* Logistic Regression
* Decision Tree Classifier
* K-Nearest Neighbors (KNN)

A bar chart is generated to visualize and compare model performance.
